Split screen: how does it work in MintooSuite?
Menu > Split screen shows two windows at once (for example a chart above and your trades below).

One coin in 2 to 4 windows (build 404): how does it work in MintooSuite?
Split Charts has a new box at the top: pick the exchange (Binance, MEXC, Bitget, Bybit, OKX, KuCoin, Coinbase or Kraken), type a coin (or use the coin from your chart) and tap 2, 3 or 4 windows. The same coin opens in that many panes, each on a different time frame: 2 = 15m and 1h; 3 = 1m, 15m and 1h; 4 = 1m, 15m, 1h and 4h. You can still change any pane afterwards. The ⛶ Full screen button (same box) shows the split you have, one coin or many, in the whole screen with the same panes at full size; Long/Short buttons sit on top: one set when all panes show the same coin, a set for each coin when the panes show different coins (exchanges the app can trade). Back or Exit full screen returns.
