Lesson: tables and fractions (offline): how does it work in MintooSuite?
Tables: multiplication is repeated addition. 3 x 4 = 3+3+3+3 = 12. Learn 2, 5 and 10 first, then 3, 4, 9 (9 x n digits add to 9: 9x7=63, 6+3=9), then the rest. Fractions: a fraction is part of a whole. 3/4 means 3 parts out of 4 equal parts. Same bottom: add the tops (1/5 + 2/5 = 3/5). Different bottoms: make them the same first (1/2 + 1/3 = 3/6 + 2/6 = 5/6). Simplify by dividing top and bottom by the same number (6/8 = 3/4). Decimal: 1/2 = 0.5, 1/4 = 0.25. Percentage: 25% = 25/100 = 1/4. To find 20% of 80: 80 x 20/100 = 16.

Lesson: algebra and Pythagoras (offline): how does it work in MintooSuite?
Equation: keep both sides balanced. Solve 2x + 3 = 11: subtract 3 -> 2x = 8; divide by 2 -> x = 4. Quadratic ax^2 + bx + c = 0 has x = (-b ± sqrt(b^2 - 4ac)) / 2a. Example x^2 - 5x + 6 = 0: a=1,b=-5,c=6, b^2-4ac = 25-24 = 1, x = (5 ± 1)/2 -> x = 3 or 2. Check: 3^2 - 15 + 6 = 0. Pythagoras (right triangle): a^2 + b^2 = c^2, c is the longest side. If the sides are 3 and 4: 9 + 16 = 25 so c = 5. Area of triangle = 1/2 x base x height; circle area = pi r^2 (pi ~ 3.14), circumference = 2 pi r.

Lesson: photosynthesis (offline): how does it work in MintooSuite?
Plants make their own food using sunlight. Carbon dioxide (from air through stomata) + water (from roots) -> glucose + oxygen, in the green part called chloroplast, which contains chlorophyll that absorbs light. Equation: 6CO2 + 6H2O + light -> C6H12O6 + 6O2. Glucose is energy and building material; oxygen is released. Needs: light, water, carbon dioxide, chlorophyll. Test: a leaf kept in the dark makes no starch (iodine stays brown); a leaf in light turns blue-black. Plants are producers, the base of every food chain. Practice: why do leaves look green? Why do plants need roots and leaves for this?
